# Database and Storage

## Current Implementation

> [!WARNING]
> **No Direct Database Access:** The Next.js repository analyzed here **does not contain any database connection logic**. It does not use ORMs (Prisma, TypeORM) or database drivers (pg, mysql).

## Storage Mechanisms
All persistent data generated by this application is either:
1. Cached locally in the browser (`sessionStorage` for tokens).
2. Saved remotely via external API routes (which store data in an external, undocumented database like PostgreSQL or Azure Cosmos DB managed by the Semantic Kernel backend).
3. Pushed directly to Microsoft Fabric / OneLake via external services.

The frontend retrieves historical and active state entirely by querying `/api/activities` and `/api/monitoring-logs` endpoints.
