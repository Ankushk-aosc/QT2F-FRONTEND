# Results Module

## Location
- `components/tabs/ResultTab.tsx`

## Functionality
This is the final state of a successful migration. It fetches the final output JSON from `/api/migration/results` and displays:
1. Links to the Fabric Workspace.
2. Links to the Semantic Model (Dataset).
3. Links to the generated blank Report.
4. Summary metrics of how long the migration took and what was converted.
